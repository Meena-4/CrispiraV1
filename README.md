# Crispira - CRISPR gRNA Design MVP

This is a minimal Streamlit app that helps design and score CRISPR guide RNAs (gRNAs) for gene editing.

## Features
- Input target gene name and DNA sequence  
- Predict on-target activity score (simulated Azimuth API)  
- Predict off-target risk (placeholder scores)  
- Ethical flagging for sensitive genes  
- Interactive, easy-to-use interface via Streamlit

## How to Run Locally
1. Make sure you have Python installed (recommend 3.8+)
